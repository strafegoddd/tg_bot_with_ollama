Python — высокоуровневый язык программирования общего назначения.
Python поддерживает объектно-ориентированное, процедурное и функциональное программирование.

Переменные в Python используются для хранения данных.
Для создания переменной не требуется указывать её тип явно.

Основные типы данных Python:
int — целые числа.
float — числа с плавающей точкой.
str — строки.
bool — логические значения.
list — списки.
tuple — кортежи.
dict — словари.
set — множества.
