Список в Python — изменяемая упорядоченная коллекция элементов.

Списки создаются с помощью квадратных скобок.

Пример:

numbers = [1, 2, 3, 4, 5]

Для добавления элемента используется метод append().
Для удаления элемента можно использовать remove() или pop().
Для получения длины списка используется функция len().

Элементы списка имеют индексы, начиная с нуля.
